# Squish & Pet
Squish & Pet is a clone of Undertale's fighting system, made in MS-DOS as a 5-day high school project in 2023. The code isn't the prettiest, but it's still somewhat fun in my opinion.
I'd like to revisit this in the future, but I never had the time to do so yet.

Maybe soon.

For those wondering, I ended up getting a ~95% on the project!

# Controls & OS
Controls range from the classic WASD, and expanding it to include diagonals via QEZC as well, making a QWEASDZC. Other keys like the numbers are also needed to select options.

For the OS, since it's coded in MS-DOS, this was only intended for Windows Computers.
# Code Quality & Comments
The quality of this code is absolutely terrible. There's a large lack of comments, as everything was typed in several days, in regular notepad.
Make sure you have a good CPU, the command line is quite slow at rendering >250 variables on one screen, haha!
